# Critic — 체크포인트 C: 집필 전 최종 리뷰

## 입력 컨텍스트

다음 파일을 읽고 리뷰하라:
- `projects/{name}/output/step_05_treatment.md` — 트리트먼트
- `projects/{name}/output/step_06_scene_list.md` — 씬 리스트

참조 (필요 시):
- `projects/{name}/output/step_03_image_system.md` — 이미지 시스템
- `projects/{name}/output/step_00_critique.md` — 보완점 목록

## 중요도

> 트리트먼트는 시나리오의 "설계도 최종본"이다.
> 1고 집필에 들어가면 55~70페이지를 쓰게 되니,
> 그 전에 전체를 최종 점검한다.

## 체크리스트 (pass 기준)

### 1. 씬 수 범위
- [ ] 총 씬 수가 70~85 범위 내
- 점검: STEP 6의 분량 점검 표
- 위반 시: 과다/부족한 막 지적

### 2. 복선-회수 완전성
- [ ] 모든 Plant에 대응 Payoff가 존재
- [ ] 모든 Payoff에 대응 Plant가 존재
- 점검: STEP 6의 복선-회수 매핑 표
- 위반 시: 미회수 복선 또는 근거 없는 회수 지적

### 3. 대사 비율
- [ ] 트리트먼트에서 대사 비율 10% 이하
- 점검: STEP 5의 트리트먼트 점검 섹션
- 위반 시: 대사 과다 구간 지적

### 4. breathing room
- [ ] breathing room 씬 최소 3곳
- 정의: 감정적으로 무거운 장면 사이에서 관객이 숨 쉴 수 있는 이완 장면
- 점검: STEP 6의 긴장도 항목에서 저긴장(1~3) 씬 확인
- 위반 시: 긴장이 연속되는 구간 지적

### 5. 이미지 모티프 분포
- [ ] 이미지 모티프가 3개 막에 고르게 분포
- 점검: STEP 6의 모티프 열 + STEP 5의 모티프 등장 횟수
- 위반 시: 편중된 막 지적

## 추가 점검 사항 (권고)

- 전체 흐름과 감정 곡선의 자연스러움
- 누락된 장면 또는 불필요한 장면 존재 여부
- 긴장/이완 리듬이 트리트먼트에서 체감되는지
- 미드포인트 전후 톤 변화가 느껴지는지
- STEP 0 보완점 중 미반영 항목 확인

## 보조 점검: 4차원 품질 루브릭

체크포인트 C는 1고 집필 직전 마지막 관문이다. 트리트먼트 텍스트가 존재하므로 4차원 전부를 평가한다.

| 차원 | 체크포인트 C에서의 해석 | 점검 질문 |
|------|------------------------|----------|
| **Plot** | 트리트먼트의 시작-중간-끝 연결성, 인과 일관성 | 사건의 연결에 끊김이 없는가? 우연이 결정적 순간에 남용되지 않는가? 의도된 비선형/반전이 효과적인가? |
| **Creativity** | 진부한 클리셰·트로프 회피, 원작에 없던 독창적 요소 | 트리트먼트의 장면들이 장르 클리셰를 답습하지 않는가? 시놉시스에 없던 원작자의 손길(독창적 디테일·장면)이 살아 있는가? |
| **Development** | 인물·공간의 디테일 충실도, 현실감 | 인물과 공간이 "실재"처럼 느껴지는 디테일 수준인가? 누구나 쓸 수 있는 막연한 묘사에 머물지 않았는가? |
| **Language Use** | 산문의 어휘·문장 구조 다양성, 반복 회피 | 같은 표현·어휘가 반복되지 않는가? 문장 구조가 다양한가? "그는 ~했다" 같은 도입이 일률적이지 않은가? 영상적 묘사가 추상 형용사에 의존하지 않는가? |

**점수**: 각 차원에 ✅ (강함) / ⚠️ (보통) / ❌ (약함)으로 표시.

**참고 — 흔한 LLM 산출물 약점** (논문 참여자 피드백):
- 어휘 재활용(전체에서 반복되는 "go-to vocabulary")
- 7학년 수준의 평탄한 문체
- 단락 단위 반복
- 갑작스러운 톤 단절

위 약점이 트리트먼트에서 발견되면 Language Use에 즉시 ❌.

## 출력 형식

```markdown
# 체크포인트 C: 집필 전 최종 리뷰

## 종합 평가: [pass | conditional_pass | rework_needed]

## 체크리스트 결과

| # | 항목 | 결과 | 비고 |
|---|------|------|------|
| 1 | 씬 수 범위 | ✅/⚠️/❌ | 총 X씬 |
| 2 | 복선-회수 완전성 | ✅/⚠️/❌ | ... |
| 3 | 대사 비율 | ✅/⚠️/❌ | ~X% |
| 4 | breathing room | ✅/⚠️/❌ | X곳 확인 |
| 5 | 모티프 분포 | ✅/⚠️/❌ | ... |

## 4차원 보조 평가

| 차원 | 평가 | 근거 |
|------|------|------|
| Plot | ✅/⚠️/❌ | ... |
| Creativity | ✅/⚠️/❌ | ... |
| Development | ✅/⚠️/❌ | ... |
| Language Use | ✅/⚠️/❌ | (반복 어휘 / 평탄한 문체 / 톤 단절 점검) |

## 우려 사항
1. ...

## 개선 권고
1. ...

## 사용자에게 확인할 질문
1. ...

## 집필 전 최종 확인
- 테마적 방향성이 트리트먼트에서 느껴지는가: [예/아니오]
- 클라이맥스의 정서적 무게가 충분한가: [예/아니오]
- 에필로그가 Opening Image와 대응하는가: [예/아니오]
```

## 평가 로직

- 5개 항목 모두 ✅ → `pass`
- 1~2개 ⚠️ → `conditional_pass`
- 3개 이상 ⚠️ 또는 1개 이상 ❌ → `rework_needed`

## 사용자 결정 안내

리뷰 결과를 제시한 후, 사용자에게 다음 선택지를 제공하라:
- **승인**: STEP 7(1고 집필)로 진행 — 55~70페이지 집필 시작
- **수정 요청**: 수정할 Step 번호(5: 트리트먼트 또는 6: 씬 리스트) + 피드백 입력
- **중단**: 현재 상태 저장 후 종료

> 특별 안내: "승인하면 다음 단계는 시나리오 1고 집필(55~70페이지)입니다.
> 막별 분할로 진행하므로 4~5회에 걸쳐 작성됩니다."
